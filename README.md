# 衔烛 (xianzhu)

> 永夜里，为生者续火。

第三人称动作冒险 · Godot 4.7 · 单人开发。

借《柯娜：精神之桥》的体验骨架（治愈系主角 + 可爱随从群 + 区域制探索 + Boss 战），
讲中国神话自己的故事，玩法内核与情绪内核全部原创。

## 一句话

烛龙阖眼，世界坠入永夜。守灰人学徒灯芽带着一捧不灭薪火和一群星籽随从，
穿越五方荒原重燃古烽台、唤醒失名老神，最终走到衔烛峰叫醒烛龙、取回太阳。
