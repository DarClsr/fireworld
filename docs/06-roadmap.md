## 里程碑

### M0 · 灰盒切片（本轮目标）
新 Godot 4.7 项目：第三人称角色控制器（SpringArm 相机）+ 拨火棍轻重攻击打
木桩 + 首颗星籽 boids 跟随。
**验收**：跑通以上三条且帧率稳定；星籽行为肉眼不穿模、不掉队卡墙。

### M1 · 招牌画面 + 木籽全交互 ✅（2026-08-27 完成）
夜幕世界（体积雾+月光+全屏色调叠加）+ 灰盒烽台点火推夜完整演出；
木籽投掷 → 枯藤锚点长桥 → 过沟 → 烽台交互的闭环玩法；动作白名单推迟到 M2。
**验收结果**：冒烟自检 15 项全绿（含掷籽消耗/长桥/过沟/点火/计数）；
四张截图（夜营/藤桥/推夜/基准）审图通过；iGPU 720p 含体积雾 53 FPS。
宣传片种子镜头 = `tmp/m1_beacon.png`（暖光穹顶压冷蓝永夜 + 藤桥引路）。

### M2 · 开局章：灰窑村序章 + 青竹渡（体验顺序优先）
玩家从灰窑村醒来接薪火，一路走到青竹渡打完首个 Boss。序章复用 M0/M1 已验证系统
（攻击 / 星籽 / 推夜），新增仅两件：自制轻量对话框、翻滚动作（补 M0 欠账）。
村庄模块建筑管线在灰窑村首跑，青竹渡聚落复用。
- **A 灰窑村序章（~10 分钟）**：醒来 → 移动/轻重攻击/翻滚教学 → 授薪火仪式演出 →
  领 3 颗原始星籽 → 村口迎宾烽火预演「推夜」→ 出村。
- **B 青竹渡（15–20 分钟）**：渡船入竹海 → 木籽谜题 → 行罩怪教学
 （土行罩，木克土首秀）→ 苇荡迷径 → 聚落烽台+句芒剧情 → Boss 怨渡人（浮筏）。
**验收**：不开作弊从灰窑村通关到怨渡人倒下，全程 25–30 分钟不卡关；
冒烟测试扩到相克破盾与序章触发链；截图+审图；验证即推。

### M3 · 管线复制铺量
赤霞隘 / 黄土塬 / 鸣沙关 用 M2 成熟的管线批量铺内容，
散布工具插件化。内容优先，平衡最后统一调。

### M4 · 收口
寒潭镜泊 + 衔烛峰两段决战、结局演出、Credits 与资产清册核对、性能分档。

## 技术决策记录（ADR）

| # | 决策 | 理由 |
| --- | --- | --- |
| D1 | Godot 4.7 stable · Forward+ | 团队既有积累；SDFGI 关闭、体积雾分区开 |
| D2 | 星籽不用 RVO，boids 自制 | 该规模下 RVO 是负优化（wuxing 实测教训） |
| D3 | 存档 JSON UTF-8 明文 | 可手改可 diff，headless 单测友好 |
| D4 | 五行判定/存档/boids 做成独立模块 | 沿用既有 headless 自退出测试经验 |
| D5 | 第三方包不入库原包，只入导出 .glb | 仓库瘦身 + 许可清晰 |
| D6 | 「推夜」用体积雾+真实光源+全屏色调叠加实现，弃深度重建后处理 | Godot 4 Forward+ 反向 Z 重建易踩坑；真实光照雾穹效果更好、性能可控，depth-mask 方案留作后续增强 |
| D7 | 核显性能档：无 MSAA、体积雾 volume_size=32/length=48、屏幕纹理禁 mipmap、无 bloom | 实测 720p 含雾 53 FPS（30→53）；着色器编译期前 ~90 帧的低帧率不算数 |
