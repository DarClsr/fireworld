# 01 概念定位

- **类型**：第三人称动作冒险（区域制，非开放世界）
- **引擎**：Godot 4.7 · Forward+
- **规模预估**：主线 4–6 小时，5+1 个区域，Boss 6 场
- **情绪基调**：温暖中带怅然——对标柯娜的档位，但内核从「死亡安息」换成「传承续火」

## 设计支柱（所有取舍以此裁决）

1. **火即进度**。点亮的烽台把夜推开一块真实的光域，地图进度肉眼可见。「赶路去点火」天然成立，不需要任务清单。
2. **群体即钥匙**。星籽随从不是宠物，是功能道具：五行形态各自解锁环境交互，收集欲和解谜锁合在同一个系统上。
3. **遗忘不是死亡**。敌人不杀生、只吃记忆；被救的老神不是复活的亡者，而是重新被人记得的名字。战斗、叙事、美术都服务这个差异。

## 与柯娜的对照表（借结构不借皮）

| 维度 | 柯娜：精神之桥 | 衔烛 |
| --- | --- | --- |
| 情绪内核 | 送死者安息、向前走 | 为生者续火、被记得 |
| 世界观来源 | 波利尼西亚 + 泛灵论 | 山海经烛龙 + 五方神（句芒/祝融/后土/蓐收/玄冥） |
| 随从 | 腐灵 Rot：收集换增益，纯可爱向 | 星籽：可烙五行印记变形成五种工具形态 |
| 战斗资源 | 性能量条驱动法术 | 相生连链增幅 / 相克破防的行气博弈 |
| 进度表达 | 收集品数值、帽子升级 | 烽火点亮 → 夜幕 shader 上真实的可见光域 |
| 视觉路线 | 写实级皮克斯高模 | 低模顶点色 × 灰阶噪声 + 体积雾 + 剪影大体积 Boss |

## 我们不做的事

- 不做死亡向导剧情，不出现「安息吧」式结局；
- 不做技能树数值成长堆叠（成长走被动符文「火纹刻痕」，见 03 文档）;
- 不追写实渲染，画质上限主动锁死在风格化路线上。
