# 03 系统拆解

数值均为首发草案，纵向切片阶段验证后再调。平衡整体延后（内容优先）。

## 星籽系统（核心特色）

### 基础行为

- 从 3 颗起步，上限 12 颗（完成度奖励逐步扩容）。环形编队跟飞，boids 自制，
  不用 RVO（此前项目实测该规模不需要）。
- 数量影响两件事：薪火照亮半径、投掷行为的威力档位（见战斗）。

### 五行烙印（工具化）

星籽可消耗「火绒」烙上一种行印记变成功能形态，随摘随换：

| 形态 | 环境交互（钥匙职能） | 战斗职能 |
| --- | --- | --- |
| 木籽 | 藤蔓搭桥、催生爬墙点、激活枯树平台 | 生链起点；缠绕减速 |
| 火籽 | 点燃机关、引燃草丛蔓延开路 | 主输出形；点燃扩散 |
| 土籽 | 堆土台垫脚、加固残垣承重 | 格挡姿态；替主人挡一次 |
| 金籽 | 切断锁链、斩断结晶藤 | 破防主力；穿透直线弹 |
| 水籽 | 浇灭焦土、结冰成桥、驱动水车 | 克火必备；湿润标记 |

原始形态（无印记）= 跟飞照明 + 卖萌。视觉上就是同一球体的五套配色+微缩放+
粒子尾巴差异，shader 手活即可，零建模成本。

### 相生相克博弈

- **相生充能**：按 木→火→土→金→水→木 的顺序连续命中，叠加增伤层（每层
  +20%，上限三层）。鼓励玩家临场编排命中顺序。
- **相克破防**：带行气罩的敌人只能被克行攻击清空护盾一次击破
  （水克火、火克金、金克木、木克土、土克水）。区域性谜题与敌配共用此规则。

## 战斗系统

### 动作集（克制，不做连招表海）

- 轻攻击 ×3 连段：拨火棍横扫，第三段小位移；
- 重攻击：蓄力火星迸溅，小型范围伤害+点燃草丛联动；
- 翻滚：0.3s 无敌帧；
- 投掷星籽：投出当前选中形态，执行上表职能，冷却 2s；
- 薪火爆发：范围脉冲，资源为「火候」（命中回涨、篝火回满），兼解谜触发器。

### 敌人初步 roster

| 类型 | 行为 | 教学点 |
| --- | --- | --- |
| 雾影（杂兵） | 直线扑、被抓掉记忆值而非血量 | 基础闪避 |
| 行罩怪 | 带单行护盾 | 相克首次教学 |
| 执灯卫（精英） | 前 human 守夜人，提灯召雾 | 打断优先级 |
| 游荡者 | 无敌意环绕，可救可无视 | 世界观的温柔：可以不打 |

「记忆值」设定：受到致命伤不是死亡而是被「抹去一段」，读档即找回——死亡惩罚
温和化，符合基调，也降低单人开发的失败挫败设计负担。

## 烽火循环系统（进度骨架）

- 每区域一座古烽台：抵达 → 解谜燃起 → 夜幕 shader 在世界空间推开一块持久
  光域 → 区域内聚落苏醒（商店 / 支线 / 篝火）。
- **篝火 = 存档点 + 火绒补给 + 星籽编队整理**，兼 soft reset。
- 大地图 UI 直接渲染当前光域边界，进度零文案成本。

## 成长系统

- **无等级、无经验**。成长走「火纹刻痕」：老神赠礼与大世界探索获得的被动
  符文，插槽生效（例如：翻滚留下火星、重击半径+15%）。全收集约 18 枚。
- 五行钥匙本身就是主线成长曲线：新形态 = 新区域通行证（类 Metroidvania 门）。

## 存档与测试友好

- 单存档位 + 篝火自动存档；格式 JSON UTF-8，纯文本可手改。
- 存档、五行判定、boids 全部做成可 headless 单测的独立模块
 （沿用 voxel-town / wuxing-rts 已验证的 headless 自退出测试经验）。
