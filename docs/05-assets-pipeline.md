# 05 资产管线（零建模路线）

原则：**程序员的美术 = 资产库 + Mixamo + 自有 shader 手艺**。
所有第三方资产在使用时逐一记录来源与许可到 `game/assets/CREDITS.md`。

## 资产映射表

| 类别 | 来源 | 处理 |
| --- | --- | --- |
| 主角 / 人形 NPC | KayKit Adventurers + Mixamo 动画 | 斗笠、幡带等用极简几何件附加；顶点色覆写统一色板 |
| 星籽 ×6 形态 | 自制：球体基模 | 六套 shader 配色+缩放+粒子尾迹（见 shader 清单②） |
| 夜魇杂兵 | Quaternius Monsters 免费包 | 去饱和漂白向夜色调色，剪影化处理 |
| 游荡者 / 执灯卫 | Quaternius Characters 重着色 | 姿态放缓、灯笼为唯一光源，氛围靠打灯 |
| 区域 Boss | 现成包拼装放大 + 剪影材质 | 大体积+fresnel 边缘光遮细节，「示弱即氛围」 |
| 场景模块 | KayKit Dungeons / Kenney Nature 等 CC0 包 | 全部过一遍顶点色×灰阶噪声斑驳（继承 hd2d 已验证管线） |
| 地形 | Terrain3D (GDExtension) | 高度笔刷雕刻 + 分层绘制 |
| 植被散布 | 自制 MultiMesh 散布工具 | 从 voxel-town 的自动化经验迁移，FastNoiseLite 掩码 |
| 天空/大气 | ProceduralSkyMaterial + 体积雾 + 辉光 | 每区域一个「永恒时刻」光位预设 |
| 动画 | Mixamo（人形全部）；生物用资产包自带动画集 | glTF 优先；FBX 注意 -Y up 与 scale 导入修正 |

## Shader 需求清单（自研工单）

1. **夜幕世界遮罩**：~~全局夜色滤镜+光域反转~~ → 按 ADR D6 落地为「体积雾 + 真实光源推夜 + 全屏冷色调叠加」，已验收（M1）；深度重建式遮罩留作可选增强；
2. **星籽呼吸**：噪声驱动的 emissive 脉冲 + 跟飞拖尾，hd2d 顶点色噪声经验的直系应用;
3. **场景件统一旧化**：顶点色 × 灰阶噪声做新旧斑驳，一条 material override 走天下;
4. **薄冰水面**：冰桥生成动画 + 半透折射近似;
5. **老神剪影体**：fresnel rim + 半透明 + 内部微光粒子，大 Boss 气质担当。

## 风险与对策

| 风险 | 对策 |
| --- | --- |
| 中国风模块包稀缺（现成库偏西幻） | A. 低模通用件当骨架 + 中式配色覆写 + 斗笠/灯笼/幡旗/屋脊吻兽等几何极简点缀件自制；B. 关键单件（屋顶、石狮）预算内低成本定制外包 |
| 角色脸型不够「中式」 | 构图策略规避：中景为主、斗笠披风遮挡、剪影演出承担特写 |
| 体积雾性能（永夜全开） | 未点亮区才开浓雾，光域内切档；分区域常量配置而非全局一档 |
| Mixamo 动画风味混杂 | 收一版「官方动作白名单」（待 M1 定），其余一律不用 |

## 工程约定

- 资产格式 glTF 优先；导入走 Godot import presets 统一配置并入库。
- 第三方包原包不入库，只入库导出后的 .glb + 许可文件，保持仓库瘦身。
- `game/assets/CREDITS.md` 与发行时的 Credits 画面共用同一数据源。
